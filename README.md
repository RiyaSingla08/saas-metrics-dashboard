# SaaS Metrics Dashboard

A lightweight, local, open-source BI dashboard for SaaS metrics — MRR, churn, LTV, and cohort retention — built with Python, Dash, DuckDB, and Plotly.

> 🚧 Work in progress. Full setup instructions and screenshots coming as the project is built out.

## Quick start (coming soon)

```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python app/main.py
```
